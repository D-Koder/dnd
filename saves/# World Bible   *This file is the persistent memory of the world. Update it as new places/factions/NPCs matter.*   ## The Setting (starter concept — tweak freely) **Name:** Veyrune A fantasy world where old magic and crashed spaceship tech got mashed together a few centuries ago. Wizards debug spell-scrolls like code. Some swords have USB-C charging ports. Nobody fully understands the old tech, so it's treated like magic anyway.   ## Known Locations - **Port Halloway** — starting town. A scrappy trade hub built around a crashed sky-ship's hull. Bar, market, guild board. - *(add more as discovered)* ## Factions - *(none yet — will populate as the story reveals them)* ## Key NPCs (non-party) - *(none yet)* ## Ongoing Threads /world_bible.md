## The Setting (starter concept — tweak freely)
**Name:** Veyrune
A fantasy world where old magic and crashed spaceship tech got mashed together a few centuries ago. Wizards debug spell-scrolls like code. Some swords have USB-C charging ports. Nobody fully understands the old tech, so it's treated like magic anyway.
